# Security

The port runs code on players' PCs (the app, the compiler it downloads, code mods recompiled into the game's library) and talks to other players over the network (rooms, the lobby server). If you find a way to abuse any of that — a crafted network packet, a mod archive that writes outside its folder, a download that isn't checked, a leaked token — please report it privately:

- use **GitHub's private vulnerability reporting** (the *Security* tab → *Report a vulnerability*), or
- if that isn't available, open an issue that says only "security report, please contact me" and the maintainer will reach out.

Please don't post details publicly until a fix is out. Reports are welcome in English or Spanish.

Not security problems: the game itself crashing, a mod that misbehaves in the game, or anything that needs the attacker to already control your PC.
